1. Introduction to HTML

HTML = HyperText Markup Language. It is the language used to build web pages. Hypertext = text with links that jump to other pages. Markup = you “mark” text with tags that tell the browser how to show it. HTML is not a programming language (no calculations or decisions); it only describes how a page looks.

A tag is a word in angle brackets, e.g. <p>. Most come in pairs: an opening tag <p> and a closing tag </p> (with a slash). Some have no closing tag (<hr>, <br>, <img>); these are empty tags. An attribute gives extra information inside the opening tag: <font color="red"> (name = value). Tags are not case-sensitive. How to use it: type the code in Notepad, save as page.html, open it in a browser (Chrome, Edge, Firefox).

2. Why HTML? Advantages and disadvantages

Advantages

  • Easy to learn and write; any text editor will do.
  • Free; no special software needed.
  • Platform independent: works on Windows, Linux, Android; all browsers understand it.
  • Light and fast to load.
  • Supports links (hyperlinks), images, audio and video, tables and lists.
  • Base for all websites; can be combined with CSS and scripts.

Disadvantages

  • Only static pages; no logic, calculation or database handling on its own.
  • Little security.
  • Large sites are hard to maintain; every page must be edited by hand.
  • Limited control over layout and design without CSS.
  • Needs other tools (scripting languages) for interactivity; tags must be remembered; a small typing mistake can break the layout.

Other useful tags and attributes

  • Headings <h1> (largest) to <h6> (smallest), with align.
  • Comment (not shown): <!-- note -->. Special characters: &nbsp; (space), &lt; (<), &gt; (>), &amp; (&).
  • Colours can be names (red) or hex codes (#FF0000), used in bgcolor, text, color.

5. Images and links

<img src="photo.jpg" alt="My photo" height="150" width="200" align="right">
  • IMG – inserts a picture (empty tag).
  • SRC – source: file name or path of the image.
  • ALT – alternate text shown if the image cannot load (also used by screen readers).
  • HEIGHT, WIDTH – size in pixels (or %).
  • ALIGN – position/text wrap: left, right, top, middle, bottom. (border sets a frame.)

Links use the anchor tag <A> and the HREF (hypertext reference) attribute, which holds the address to open:

<a href="https://www.example.com">Visit site</a>      absolute link (another site)
<a href="page2.html">Next page</a>                    relative link (your own file)
<a href="mailto:me@mail.com">Mail me</a>              opens email
<a href="page2.html"><img src="go.jpg" alt="Go"></a>  image as a link

Horizontal lines (HR) can separate sections and take width, size and align as shown in Section 3.

7. Scripting as language support: VBScript

HTML alone cannot think. A script is a small program placed inside the page to add logic. VBScript (Visual Basic Script, by Microsoft) is a simple scripting language placed between <script language="VBScript"> and </script>. It runs inside the browser. (Note: only old Internet Explorer runs VBScript; modern browsers ignore it, but it is in your syllabus, so learn the syntax.)

StatementPurposeForm
DIMdeclares (creates) variablesDim a, b, total
SETassigns an object to a variableSet obj = CreateObject("Scripting.Dictionary")
MsgBoxshows a message window to the userMsgBox "Hello", 64, "Title"
InputBoxasks the user to type something; returns it as textn = InputBox("Enter a number", "Input")
IF … THEN … ELSEdecisionIf x > 5 Then … Else … End If
FOR … NEXTloop a fixed number of timesFor i = 1 To 5 … Next (optional Step 2)
<html><body>
<script language="VBScript">
  Dim n, i, total
  n = InputBox("Enter a number")
  total = 0
  For i = 1 To n
      total = total + i          ' adds 1+2+...+n
  Next
  If total > 10 Then
      MsgBox "Sum is " & total & " (big)"
  Else
      MsgBox "Sum is " & total & " (small)"
  End If
</script>
</body></html>

Notes: & joins text; ' starts a comment; variables need no type; every If ends with End If and every For with Next.

Extra topics from the revised syllabus

  • Classification of tags: container (paired) tags like <p>…</p> and empty tags like <br>, <hr>, <img>. HTML editors: text editors (Notepad, Notepad++, VS Code) or WYSIWYG editors (Dreamweaver).
  • <basefont size="4"> sets the default font; <center> centres content; <address> shows contact details (in italics); <em> emphasis (italic), <strong> strong (bold), <strike> strikethrough.
  • Colour scheme on <body>: bgcolor, text, link (unvisited), vlink (visited), alink (active).
  • Definition list: <dl><dt>Term</dt><dd>Meaning</dd></dl>. Nested list: put a <ul> or <ol> inside an <li>.
  • Table sections: <thead> (header rows), <tbody> (body), <tfoot> (footer). colspan="2" merges cells across columns; rowspan="2" merges down rows. Events such as onmouseover and onclick can be added to <td> to run script.
  • <script language="VBScript"> … </script> is the tag that holds script code (Section 7).
