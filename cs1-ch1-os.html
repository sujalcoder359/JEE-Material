1. What is an operating system?

A computer is just hardware: CPU, memory, disk, keyboard, screen. It can do nothing useful alone. The Operating System (OS) is the system software that manages the hardware and gives programs a place to run. It acts as a middleman between the user (and programs) and the hardware. Without it you would have to control the hardware yourself in 0s and 1s.

Two goals: (1) make the computer convenient to use, (2) use the hardware efficiently. Examples: MS-DOS, Windows, Linux, Unix, macOS, Android. The OS is often called a resource manager, because it shares CPU time, memory, files and devices among programs. The core part that is always in memory is the kernel; the part you type commands into is the shell.

2. Services provided by an OS

  • Program execution – loads a program into memory and runs it, then ends it.
  • I/O operations – programs never touch devices directly; the OS does it for them.
  • File-system manipulation – create, delete, read, write, rename files and folders.
  • Communication – processes exchange data (on one computer or across a network).
  • Error detection – watches for faults (printer out of paper, memory error) and takes action.
  • Resource allocation – decides who gets CPU, memory, devices.
  • Accounting – records which user used how much.
  • Protection and security – stops one user or program from harming another; passwords.

3. Overview: Windows 98, Windows NT, Linux

Windows 98

Made by Microsoft (1998), for home PCs. Features: GUI with icons and the Start button; single-user but multitasking; Plug and Play (new hardware is detected and set up automatically); support for USB; FAT32 file system for large disks; built-in Internet Explorer and Internet connection support; good multimedia support; long file names.

Windows NT (New Technology)

Microsoft’s professional / network OS for servers and business workstations. Features: full 32-bit, preemptive multitasking; multi-user network support; NTFS file system with file-level security and permissions; high security and reliability (a crashing program does not bring down the system); portable across different processors; client-server design; two flavours: NT Workstation and NT Server.

Linux

Created by Linus Torvalds in 1991; based on the older Unix. Features of Linux (a favourite 6-mark list):

  1. Free and open source – anyone can see, change and share the code.
  2. Multi-user – many users can work at once on separate accounts.
  3. Multitasking – many programs run together.
  4. Portable – runs on many kinds of hardware.
  5. Secure – passwords, file permissions, very few viruses.
  6. Stable and reliable – rarely crashes; used on servers.
  7. Shell – powerful command interpreter, with scripting.
  8. Hierarchical file system – one directory tree starting at / (root).
  9. GUI support – desktops such as GNOME and KDE; and good networking support.

4. Information (file) management – definitions

File system
The part of the OS that decides how files are named, stored, organised and retrieved on a disk. It keeps folders (directories) in a tree, tracks free space, and controls who may open a file. Operations: create, open, read, write, close, delete. Examples: FAT, NTFS.
Device drivers
Small programs that let the OS talk to one particular hardware device (printer, scanner, graphics card). Each device speaks its own “language”; the driver translates the OS’s general commands into the device’s commands. No driver = device does not work.
Terminal I/O
Handling of input from the keyboard and output to the screen (the terminal). The OS reads the characters you type, shows them (echo), handles special keys like Backspace and Enter, and sends program output to the display.

5. Process management – definitions

Process
A program in execution. A program is a file sitting on disk (passive); a process is that program running in memory with its own data, counter and CPU state (active). The OS keeps each process’s details in a Process Control Block (PCB).
Multiprogramming
Keeping several programs in memory at once. When one waits for I/O, the CPU switches to another, so the CPU is never idle and is used well.
Multitasking
Running several tasks (processes) at the same time from the user’s view, such as listening to music while typing. The CPU switches between them so quickly that they seem simultaneous.
Time sharing
A multitasking method where the CPU gives each process/user a very small time slice (quantum) in turn. Many users share one computer and each feels they have it to themselves. Gives quick response.
Context switching
When the CPU leaves one process and starts another, the OS saves the state of the old process (in its PCB) and loads the saved state of the new one. It is pure overhead: no useful work is done during the switch.
Priority
A number given to each process showing its importance. The process with the highest priority gets the CPU first (e.g. system tasks before background tasks).

6. Memory management – definitions

Memory (RAM) is limited, and programs must be in it to run. The OS keeps track of which parts are free or used, gives memory to processes and takes it back.

Typical memory map of a single-user computer

High address →  [ Device drivers / ROM BIOS ]
                [ Free (unused) memory      ]
                [ User program area         ]
Low address  →  [ OS (kernel, interrupt table) ]

The OS sits in the lowest part; the single user’s program loads above it; the rest is free. Only one program runs at a time, so memory management is simple.

Partitioning

  • Fixed partitioning: memory is split into partitions of fixed size (set at start). Each process goes into one. Easy, but a small process wastes the leftover space in its partition (internal fragmentation), and the number of processes is limited.
  • Variable partitioning: partitions are created of exactly the size the process needs. No internal waste, but as processes come and go, small unusable holes appear between them (external fragmentation); fixed by compaction (sliding all processes together).

Paging

Logical memory is cut into equal blocks called pages; physical memory into blocks of the same size called frames. Any page can sit in any frame; a page table records which page is in which frame. Pages need not be side by side, so there is no external fragmentation (only a little waste in the last page).

Segmentation

The program is divided into logical parts of different sizes called segments (main code, functions, data, stack) as the programmer sees it. A segment table stores each segment’s start and length. Paging = equal physical pieces; segmentation = meaningful logical pieces.

Virtual memory

A technique that lets you run programs larger than RAM by using part of the hard disk as extra memory. Only the parts needed now sit in RAM; the rest wait on disk and are brought in when needed (demand paging). If a needed page is missing it is a page fault. Too much swapping makes the computer very slow (thrashing).

7. GUI (Graphical User Interface)

A GUI lets you use the computer by pointing and clicking pictures (icons, menus, windows) with a mouse, instead of typing commands (a CLI, command-line interface). It is easier for beginners but uses more memory and processing power.

  • Window – a rectangular area on screen where one program shows its output.
  • Task list / taskbar – shows all running programs; click one to switch to it.
  • Drag – press and hold the mouse button on an item, move, then release (to move a window or file).
  • Resize – change a window’s width and height by dragging its edge or corner.
  • Minimize – hide the window to the taskbar (program keeps running).
  • Maximize – make the window fill the screen.
  • Close – shut the window and end the program.

Other parts: icon (small picture for a program/file), menu, pointer/cursor, desktop, dialog box.

8. Access and security aspects of an OS

Security means protecting the computer, programs and data from misuse. The OS uses user accounts with passwords (authentication), file permissions (who may read/write/run), encryption, firewalls and antivirus software.

Security threats

A threat is a possible danger: unauthorised access (a stranger logs in), data theft, data modification or destruction, denial of service (making the system unusable for real users), loss from hardware failure or disaster.

Attacks on security

  • Password guessing/cracking and stealing passwords.
  • Trojan horse – a harmful program disguised as a useful one.
  • Trap door (back door) – a secret entry left in a program to bypass security.
  • Logic bomb – hidden code that goes off when a condition is met (a date, a user deleted).
  • Denial-of-service attacks, and viruses / worms below.
Computer virus
A malicious program that attaches itself to another file or program and spreads when that file is run or copied. It needs a host and human action (sharing a pen drive). Effects: deletes or corrupts files, slows the system. Types: boot-sector, file-infector, macro virus.
Computer worm
A malicious program that copies itself on its own and spreads through a network, without needing a host file or user action. It eats up memory and bandwidth and can crash networks.

Virus vs worm: a virus needs a host and user action; a worm is standalone and spreads itself over networks. Prevention: antivirus with updates, don’t open unknown attachments, keep the OS updated, use firewalls and strong passwords, take backups.

10. Extra topics from the revised syllabus

Windows NT architecture

Two modes: user mode (applications and protected subsystems, such as the Win32 subsystem) and kernel mode (full hardware access): the Executive (memory, process, I/O, security managers), the Kernel (scheduling, interrupts) and the HAL (Hardware Abstraction Layer, which hides hardware differences so NT runs on different machines).

GNU/Linux and Ubuntu

GNU = “GNU’s Not Unix”, a free-software project; Linux is the kernel; together they form GNU/Linux. Ubuntu is one of the most popular GNU/Linux distributions. It offers a GUI (desktop with icons, windows) and a CLI (terminal where you type commands such as pwd, ls, cd, mkdir, cp, mv, rm, cat).

File systems, operations, access methods

Types of file system: FAT/FAT32 (Windows 98), NTFS (NT), ext2/ext3/ext4 (Linux). Tape-based storage allows only sequential access; disk-based allows direct access. File operations: create, open, read, write, seek (reposition), close, rename, delete, truncate. Sequential access: records read one after another in order (simple, like tape). Direct (random) access: jump straight to any record by its number (fast, like disk).

Allocation methods (how disk blocks are given to a file)

Scheduling

The scheduler picks which ready process gets the CPU. FCFS (first come first served), SJF (shortest job first), Round Robin (equal time slice in turn), Priority (highest priority first). Preemptive = the CPU can be taken away from a running process; non-preemptive = it runs until it finishes or waits.
