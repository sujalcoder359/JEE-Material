Basics: what is a network?

A computer network is a group of two or more computers and devices (nodes) connected so that they can share data and resources (files, printers, internet). Advantages: resource sharing, fast communication (email, chat), lower cost (one printer for many), central backup and security. Disadvantages: setup cost, security risks, one fault can affect many.

Terms: bandwidth = how much data a medium can carry per second (bits per second, bps). Server gives services, client uses them. Protocol = agreed rules for communication. Packet = a small chunk of data sent over a network. Transmission modes: simplex (one way, like TV), half duplex (both ways, one at a time, like walkie-talkie), full duplex (both ways together, like a phone call).

1. Transmission media

The medium is the path that carries the signal. Guided (cable) media use a physical wire; unguided (wireless) media travel through air.

Twisted pair cable

Pairs of insulated copper wires twisted together so the twist cancels interference (noise). UTP (Unshielded) is cheap and common; STP (Shielded) has a metal shield for extra protection. Uses an RJ-45 connector; limit about 100 m; categories Cat5, Cat6 (100 Mbps to 1 Gbps+). Used in LANs and telephone lines.

Coaxial cable

Layers from the centre out: copper core, insulator, braided metal shield, outer plastic jacket. Better shielding than twisted pair, so it carries signals farther. Thin coax (10Base2, up to 185 m) and thick coax (10Base5, up to 500 m); uses BNC connectors. Used in cable TV and older bus LANs.

Fibre optic cable

Thin strands of glass or plastic carry data as pulses of light. Parts: core (light travels), cladding (reflects light back in), protective jacket. Types: single-mode (very long distance) and multi-mode (shorter). Very fast, long distance, no electrical interference, hard to tap (secure). But costly, fragile and harder to install.

Wireless media (introduction)

  • Radio waves: travel in all directions, pass through walls; used in radio, Wi-Fi, Bluetooth (short range).
  • Microwaves: straight-line (line of sight) between towers; used in mobile networks and long links.
  • Infrared: very short range, blocked by walls; TV remotes.
  • Satellite: signals bounce off a satellite in space; covers huge areas (TV, GPS).

2. Network topologies and access methods

Topology = the layout or arrangement of nodes and cables in a network. An access method = the rule deciding which node may use the shared cable and when, so that data does not clash.

Bus topology

=======================  backbone cable
T                     T   (T = terminator)

All nodes connect to one main cable (backbone); terminators at both ends stop signal reflection. + cheap, easy, little cable. − a break in the backbone stops everything; slow with many nodes; hard to find faults; collisions.

Ring topology

[A]──[B]
 │     │
[D]──[C]      data travels one way round

Each node connects to exactly two neighbours forming a closed loop. Data passes node to node in one direction; each node regenerates the signal. + equal access, no collisions with token passing, works under heavy load. − one node or cable failure breaks the ring; adding nodes disturbs the network.

Star topology

      [B]
       |
[A]──[HUB]──[C]
       |
      [D]

Every node connects to a central hub or switch. + easy to add or remove nodes; a failed cable affects only that node; easy fault finding; most popular today. − if the hub fails the whole network fails; needs more cable.

3. Ethernet and Token Ring

Ethernet (IEEE 802.3)

The most widely used LAN technology. Uses bus or star layout and the access method CSMA/CD (Carrier Sense Multiple Access with Collision Detection):

  1. Carrier sense: a node listens; if the cable is busy it waits.
  2. Multiple access: if idle, it sends its data; any node may do so.
  3. Collision detection: if two nodes send together a collision occurs, both stop, send a jam signal, wait a random time and try again.

Speeds: 10 Mbps (10Base-T), 100 Mbps (Fast Ethernet), 1 Gbps (Gigabit). Every network card has a unique 48-bit MAC address. A frame has: preamble, destination address, source address, type/length, data, error check (CRC).

Token Ring (IEEE 802.5)

Developed by IBM; uses a ring (wired physically as a star through a MAU, Multistation Access Unit). Access method is token passing: a small special frame called the token keeps circulating. Only the node holding the free token may send. It attaches data and marks the token busy; the frame goes round; the destination copies it; the sender removes the frame and releases a new free token. No collisions. Speeds 4 or 16 Mbps.

4. Protocols and Internet protocols

A protocol is a set of rules for how data is formatted, sent and received, so different computers can understand each other. The Internet runs on the TCP/IP suite.

  • IP (Internet Protocol): gives each device an IP address and routes packets. IPv4 is 32-bit, written as four numbers (like 192.168.1.10); IPv6 is 128-bit.
  • TCP (Transmission Control Protocol): splits data into packets, numbers them, checks they arrive (acknowledgement), resends lost ones and reassembles in order. Reliable, connection-oriented.
  • UDP: fast but no delivery check (video calls, games).

5. Connectivity devices

Modem
Modulator + Demodulator. Converts the computer’s digital signals to analog signals for telephone lines (modulation) and back (demodulation). Needed to connect to the Internet through phone or cable lines. Types: dial-up, DSL/broadband, cable.
Hub
A device with many ports that connects computers in a star network. It receives data on one port and sends it to all other ports (broadcast), whether or not they need it. All nodes share the bandwidth; it does no filtering. Active hubs also regenerate the signal.
Repeater
Receives a weakening signal, regenerates (amplifies and cleans) it and sends it on, so a network can cover a longer distance than the cable limit (e.g. beyond 100 m).
Router
Connects different networks (for example your LAN and the Internet). It reads the IP address in each packet, looks in its routing table and sends it along the best path. Smarter than a hub: it filters traffic and often includes a firewall and Wi-Fi.

Also useful: NIC (network interface card; gives a computer its network connection and MAC address), switch (like a hub but sends data only to the intended port), bridge (links two LANs) and gateway (links networks that use different protocols).
