1. Introduction to microcontroller

A microcontroller (µC) is a complete small computer on a single chip: CPU + RAM + ROM + I/O ports + timers + serial port, all inside. It is designed to control one specific task inside a device (an embedded system). A microprocessor is only a CPU and needs external memory and I/O chips.

2. The 8051 architecture and programming model

Features of the 8051 (Intel, 1980): 8-bit CPU · 4 KB on-chip ROM (program) · 128 bytes on-chip RAM · 32 I/O lines in four 8-bit ports (P0–P3) · two 16-bit timers/counters (T0, T1) · full-duplex serial port (UART) · 5 interrupts (INT0, INT1, Timer 0, Timer 1, Serial) · 16-bit PC and 16-bit DPTR · can address 64 KB external program memory and 64 KB external data memory · 40 pins · on-chip oscillator (11.0592 or 12 MHz crystal) · one machine cycle = 12 clock periods.

Memory

Internal ROM 4 KB (0000H–0FFFH) · Internal RAM 128 bytes: register banks (00H–1FH), bit-addressable area (20H–2FH), general scratch-pad (30H–7FH) · SFRs (Special Function Registers: A, B, PSW, SP, DPTR, port latches, timers) at 80H–FFH. Harvard architecture: separate memory for program and data.

Block diagram: functional parts

CPU (with ALU and registers) · 4 KB ROM · 128 B RAM · 4 I/O ports (P0–P3, 32 lines) · two timers/counters · serial port · interrupt control · oscillator and timing circuit · bus control logic, all joined by internal buses.

Timers/counters: Timer 0 and Timer 1, each 16-bit (TH + TL), controlled by TMOD (mode) and TCON (start/stop, overflow flags). As a timer they count machine cycles (to make delays); as a counter they count external pulses on pins T0/T1. Modes: 0 (13-bit), 1 (16-bit), 2 (8-bit auto-reload), 3 (split timer 0).

Serial port: full duplex through pins TXD/RXD; data held in SBUF, set by SCON; baud rate usually made by Timer 1.

Other microcontroller families: PIC (Microchip), AVR (Atmel; used in Arduino), ARM, Motorola 68HC11.

Applications of microcontrollers: washing machines, microwave ovens, TV and AC remotes, cars (engine control, ABS, airbags), mobile phones, digital cameras, toys, ATMs, security alarms, medical instruments (BP monitor), printers, traffic lights, robots, industrial control.
