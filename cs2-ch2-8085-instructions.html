The big picture

A processor only understands tiny one-step commands: “copy this”, “add these two”, “jump there if zero”. Assembly language writes those tiny steps with short names (MOV, ADD, JNZ). This chapter has three parts: where data can come from (addressing modes), the list of available commands (instruction set) and how to join them into small programs. Learn programs by tracing them: write down what A, B and HL hold after each line.

Words you need first

Binary uses 0 and 1; hexadecimal uses 0–9 and A–F (1010 = A, 1111 = F; so 0011 1010 = 3AH). Byte = 8 bits; nibble = 4 bits. Address – the number of a memory location. (HL) or M – the memory byte whose address is stored in the HL pair. Subroutine – a part of a program that is called from another place and then returns. Loop – steps repeated until a counter reaches zero.

Binary, hex and assembly basics

Binary, hex and mnemonics

The CPU only understands binary. We write hexadecimal (base 16: digits 0–9, A–F; suffix H, e.g. 2050H, FFH) because it is short. One hex digit = 4 bits, so 2 digits = 1 byte. Machine language = binary codes. Assembly language = short words called mnemonics (ADD, MOV) that stand for those codes; an assembler converts it to machine code. Opcode = the operation part; operand = the data or address it works on.

A line of assembly: LABEL: MNEMONIC operand1, operand2 ; comment. Example: LOOP: MVI A, 05H ; load 5 into A.

Instruction size: 1-byte (opcode only: MOV, ADD, INR), 2-byte (opcode + 8-bit data/port: MVI, ADI, IN, OUT), 3-byte (opcode + 16-bit address/data, low byte first: LXI, LDA, STA, LHLD, JMP, CALL).

Where does the data come from? Addressing modes

In simple words

Addressing mode = where the data is found. Immediate: written inside the instruction (the number is in your hand). Register: in a register (on the board). Direct: the instruction gives the memory address (a page number). Register indirect: a register holds the address (a note saying which shelf).

The five modes

An addressing mode is the way an instruction tells where its data is.

ModeMeaningExample
Immediatedata is inside the instructionMVI B, 32H, LXI H, 2050H
Registerdata is in a registerMOV A, B, ADD C
Directinstruction gives the memory addressLDA 2050H, STA 2060H
Register indirecta register pair holds the memory addressMOV A, M (HL), LDAX B
Implied (implicit)operand is understood, none writtenCMA, RAL, STC

What you can use: the programming model

What a programmer can use

What a programmer can use: Accumulator A (8-bit); B, C, D, E, H, L (8-bit, or pairs BC, DE, HL); flags S, Z, AC, P, CY; PC and SP (16-bit); memory up to 64 KB (0000H–FFFFH), where M means the byte at the address in HL; 256 input and 256 output ports (00H–FFH). Also see Chapter 5.

The 8085 instruction set

Reading the instruction tables

Notation: R = register A,B,C,D,E,H,L · RP = pair BC, DE, HL (or SP/PSW) · M = memory at HL · (addr) = contents of that address.

Data transfer (no flags change)

InstructionAction
MOV R1,R2 / MOV R,M / MOV M,Rcopy second into first
MVI R,data8 / MVI M,data8load 8-bit number
LXI RP,data16load 16-bit number into pair (or SP)
LDA addr / STA addrA ← (addr) / (addr) ← A
LDAX B or D / STAX B or DA ← ((BC or DE)) / store A there
LHLD addr / SHLD addrL ← (addr), H ← (addr+1) / store L, H there
XCHGswap HL and DE

Arithmetic

InstructionAction
ADD R/M, ADI dataA ← A + R/M/data
ADC R/M, ACI dataA ← A + R/data + CY (add with carry)
SUB R/M, SUI dataA ← A − R/M/data
SBB R/M, SBI dataA ← A − R/data − CY (borrow)
INR R/M, DCR R/Madd/subtract 1 (CY unaffected)
INX RP, DCX RPadd/subtract 1 on a 16-bit pair (no flags)
DAD RPHL ← HL + RP (only CY affected)
DAAdecimal adjust A after BCD addition

Arithmetic ADD/SUB etc. change all five flags (S, Z, AC, P, CY).

Logical

InstructionAction
ANA R/M, ANI dataA ← A AND … (CY = 0, AC = 1)
ORA R/M, ORI dataA ← A OR … (CY = AC = 0)
XRA R/M, XRI dataA ← A XOR … (XRA A clears A)
CMP R/M, CPI datacompare: A − operand, A unchanged. Z = 1 if equal; CY = 1 if A is smaller
CMA / CMC / STCcomplement A / complement carry / set carry
RLC / RRCrotate A left / right (CY = the bit that moved out)
RAL / RARrotate A left / right through the carry (9-bit rotation)

Branching

Normally the PC goes to the next instruction; branching changes it. Unconditional: JMP addr, CALL addr (jump to subroutine, saving the return address on the stack), RET (come back), PCHL (PC ← HL). Conditional (jump only if the flag condition is true):

JCJNCJZJNZJPJMJPEJPO
CY=1CY=0Z=1Z=0S=0 (plus)S=1 (minus)P=1 (even)P=0 (odd)

Conditional calls (CZ, CNZ, CC…) and returns (RZ, RNZ, RC…) work the same way. Loop idea: load a counter, do the work, DCR C, then JNZ LOOP (repeat until C = 0).

Stack

The stack is a memory area, last-in first-out, pointed to by SP, growing downward. PUSH RP (BC, DE, HL or PSW = A+flags): high byte to SP−1, low byte to SP−2, SP decreases by 2. POP RP: reverse, SP increases by 2. XTHL swaps HL with the top of stack; SPHL copies HL to SP. Set the stack first: LXI SP, 27FFH.

I/O and machine control

IN port (A ← data from port), OUT port (port ← A), EI / DI (enable / disable interrupts), HLT (stop), NOP (do nothing for one cycle), RIM / SIM (read / set interrupt mask and serial lines). RST n (n = 0 to 7) is a one-byte CALL to address 8 × n (e.g. RST 1 jumps to 0008H); used for software interrupts.

Writing and tracing assembly programs

In simple words

How to trace a program. Example: 05H and 03H stored at 2050H and 2051H. LXI H,2050H → HL = 2050H · MOV A,M → A = 05H · INX H → HL = 2051H · ADD M → A = 05H + 03H = 08H · INX H → HL = 2052H · MOV M,A → memory 2052H = 08H. Do this on paper for every program.

How to write a program

Steps to write any program: 1) understand the task, 2) decide where data lives (memory addresses), 3) write the logic, 4) end with HLT. Standard layout: program from 2000H, data from 2050H. Note: the board says programs should not exceed about 20–29 instructions.

1. Add two 8-bit numbers (with carry)

LXI H, 2050H   ; HL points to the first number
MOV A, M       ; A = first
INX H
ADD M          ; A = A + second
INX H
MOV M, A       ; store sum at 2052H
MVI A, 00H
ADC A          ; A = 0 + 0 + CY = carry
INX H
MOV M, A       ; store carry at 2053H
HLT

2. Subtract two 8-bit numbers

LXI H, 2050H
MOV A, M       ; A = first
INX H
SUB M          ; A = first - second
INX H
MOV M, A       ; result at 2052H
HLT

3. Add two 16-bit numbers

LHLD 2050H     ; HL = first 16-bit number
XCHG           ; DE = first
LHLD 2052H     ; HL = second
DAD D          ; HL = HL + DE
SHLD 2054H     ; store result (low, high)
HLT

4. Largest number in a block (count at 2050H, data from 2051H, count ≥ 2)

LXI H, 2050H
MOV C, M       ; C = count
INX H
MOV A, M       ; assume first is largest
DCR C
LOOP: INX H
CMP M          ; A - M
JNC SKIP       ; A >= M : keep A
MOV A, M       ; else new largest
SKIP: DCR C
JNZ LOOP
STA 2060H      ; store largest
HLT

For the smallest, replace JNC SKIP with JC SKIP.

5. Sum of N numbers (count at 2050H)

LXI H, 2050H
MOV C, M       ; counter
INX H
XRA A          ; A = 0
MVI B, 00H     ; B collects carries
LOOP: ADD M
JNC NEXT
INR B          ; count a carry
NEXT: INX H
DCR C
JNZ LOOP
STA 2070H      ; low byte of sum
MOV A, B
STA 2071H      ; high byte
HLT

6. Multiply two 8-bit numbers (repeated addition)

LDA 2050H
MOV E, A
MVI D, 00H     ; DE = multiplicand
LDA 2051H
MOV C, A       ; C = multiplier (loop count)
LXI H, 0000H   ; HL = 0
LOOP: DAD D    ; HL = HL + DE
DCR C
JNZ LOOP
SHLD 2052H     ; 16-bit product
HLT

7. 1’s and 2’s complement of a number

LDA 2050H
CMA            ; 1's complement
STA 2051H
ADI 01H        ; 2's complement = 1's + 1
STA 2052H
HLT

8. Block transfer (move 5 bytes from 2050H to 3050H)

LXI H, 2050H   ; source
LXI D, 3050H   ; destination
MVI C, 05H     ; count
LOOP: MOV A, M
STAX D
INX H
INX D
DCR C
JNZ LOOP
HLT

9. Even or odd (number at 2050H; result at 2051H: 00H even, 01H odd)

LDA 2050H
ANI 01H        ; keep only bit 0
JZ EVEN        ; bit 0 = 0 : even
MVI A, 01H     ; odd
JMP STORE
EVEN: MVI A, 00H
STORE: STA 2051H
HLT

10. Exchange two memory bytes (2050H and 2051H)

LXI H, 2050H
MOV A, M       ; A = first
INX H
MOV B, M       ; B = second
MOV M, A       ; second location = first
DCX H
MOV M, B       ; first location = second
HLT

11. Swap the two nibbles of a byte

LDA 2050H
RLC            ; rotating left 4 times swaps the nibbles
RLC
RLC
RLC
STA 2051H
HLT

12. Add two BCD numbers

LXI H, 2050H
MOV A, M
INX H
ADD M
DAA            ; decimal adjust gives the BCD result
INX H
MOV M, A
HLT
