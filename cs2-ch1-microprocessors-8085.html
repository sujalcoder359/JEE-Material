1. Evolution of microprocessors

Computers once filled rooms using vacuum tubes. Transistors, then Integrated Circuits (ICs) (thousands of transistors on a tiny silicon chip), made it possible to put the whole CPU on one chip. That chip is the microprocessor. Each new generation is faster and handles more bits at a time (a bit is one 0/1; word length = bits processed together).

Generations: 1st (4-bit), 2nd (8-bit), 3rd (16-bit), 4th (32-bit), 5th (64-bit and multi-core). Technology advanced from SSI → MSI → LSI → VLSI (more transistors per chip).

2. What is a microprocessor?

A microprocessor (µP) is a programmable electronic chip containing the entire CPU (ALU, registers and control unit) on a single IC (LSI/VLSI). It fetches instructions from memory, decodes and executes them, and produces results. It is the “brain” of a computer. By itself it is not a computer: it needs memory and I/O devices to make a microcomputer.

Features: small size, low cost, low power, high speed, reliable, programmable (general purpose). Specifications: word length, clock speed (MHz/GHz), address-bus width (decides how much memory it can use), instruction set. Uses: PCs, calculators, traffic signals, washing machines, mobiles, cars.

Buses are groups of wires that carry signals. Address bus: carries the memory/I/O address, one way (CPU → outside). Data bus: carries data, two way. Control bus: carries timing/control signals such as Read and Write.

3. Block diagram of a generic microprocessor system

ALU (Arithmetic Logic Unit)
does arithmetic (add, subtract) and logic (AND, OR, NOT, compare) operations.
Registers
tiny, very fast memory cells inside the CPU that hold data, addresses and results while working. Examples: accumulator, program counter, stack pointer, general registers.
Control unit
the manager: fetches each instruction, decodes it, and sends timing/control signals to every part to carry it out.
Memory
stores programs and data (ROM = permanent, RAM = temporary).
I/O devices
input (keyboard) and output (display) units connected through interface chips.

Instruction cycle: Fetch (read the instruction from memory) → Decode (understand it) → Execute (do it). Repeat.

Microprocessor specifications

Features that describe a microprocessor: word length (bits processed at once), clock speed, data-bus width, address-bus width (memory = 2n), instruction set, number of registers, cache, power supply and technology.

Microcomputer = microprocessor + memory (ROM, RAM) + I/O devices joined by the three buses. Keyboard interface: a circuit that detects which key is pressed, converts it to a code and gives it to the CPU. Display interface: a circuit that takes data from the CPU and drives the display (LEDs, seven-segment, screen). A microcontroller puts all of this on one chip.

4. Block diagram and architecture of the 8085

The Intel 8085 is an 8-bit microprocessor: 8-bit data bus (handles 8 bits at once), 16-bit address bus so it can address 216 = 65,536 locations (64 KB) of memory. Needs a single +5 V supply, has an on-chip clock generator (crystal of 6 MHz is divided by 2 to give about 3 MHz), 40 pins, 74 instructions (246 opcodes), 5 interrupts and serial I/O lines. Made with NMOS technology.

Parts and their jobs

ALU
performs arithmetic/logic. One input is always the accumulator, the other a temporary register; result goes back to the accumulator.
Accumulator (A)
8-bit main register; holds one operand and the result of most operations; used for I/O data.
Flag register
8 bits, of which 5 flags are used. They show the result of the last operation:
BitD7D6D5D4D3D2D1D0
FlagSZ—AC—P—CY
S (Sign): 1 if result is negative (bit D7 = 1). Z (Zero): 1 if result is zero. AC (Auxiliary Carry): 1 if a carry goes from bit 3 to bit 4 (used for BCD). P (Parity): 1 if the number of 1s in the result is even. CY (Carry): 1 if a carry/borrow comes out of the top bit.
Examples: 7FH + 01H = 80H gives S = 1 · 05H − 05H = 00H gives Z = 1 · 0FH + 01H = 10H gives AC = 1 · result 03H (two 1s) gives P = 1 · FFH + 01H = 00H gives CY = 1 and Z = 1.
General-purpose registers
B, C, D, E, H, L: six 8-bit registers, used singly or as 16-bit pairs BC, DE, HL. HL often holds a memory address (it is called M, the memory pseudo-register).
Temporary registers W and Z
used internally by the CPU during some instructions; the programmer cannot use them.
Program Counter (PC)
16-bit register holding the address of the next instruction; increases automatically after each fetch.
Stack Pointer (SP)
16-bit register pointing to the top of the stack (a memory area used to save data and return addresses).
Instruction register and decoder
the fetched opcode is held in the instruction register; the decoder works out what it means.
Timing and control unit
generates all timing and control signals (RD, WR, ALE, IO/M) and synchronises everything with the clock.
Interrupt control
handles requests from outside devices (TRAP, RST 7.5, 6.5, 5.5, INTR).
Serial I/O control
sends/receives data bit by bit through SOD and SID.
Address buffer and data/address buffer
drive the address lines A8–A15 and the shared AD0–AD7 lines.

Demultiplexing AD7–AD0

AD7–AD0 carry the low address in the first clock period and data afterwards. An external latch (74LS373) controlled by ALE catches and holds the low address, so A15–A8 (direct) plus the latch output (A7–A0) give the full 16-bit address, while the same AD lines are then free for data.
