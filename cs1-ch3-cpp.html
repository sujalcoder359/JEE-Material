1. The big picture

A computer only understands 0s and 1s (machine language). Humans write in a readable language like C++ (source code, saved as .cpp). A compiler translates the whole file into machine language; if you made a grammar mistake it shows a syntax error and refuses. A logic error means it runs but gives wrong answers. The cycle is: write → compile → run → fix.

C++ is called object-oriented: you model real things (a student, a bank account) as objects. Before that, learn the basics, which are the same in many languages.

Procedural vs Object-Oriented approach

Procedural (C)Object-Oriented (C++)
Program = list of functionsProgram = objects that talk to each other
Focus on steps (top-down)Focus on data (bottom-up)
Data is global and unsafeData is hidden inside objects (safe)
Hard to reuse or extendReuse through inheritance

Features of OOP: objects, classes, data abstraction, encapsulation, inheritance, polymorphism, dynamic binding (which function runs is decided at run time) and message passing (objects communicate by calling each other’s functions). Advantages: reusability, easy maintenance, data security, real-world modelling, easy to extend. Disadvantage: bigger programs, needs more planning.

2. Your first program, line by line

#include <iostream>   // 1
using namespace std;   // 2
int main()             // 3
{                      // 4
    cout << "Hello";   // 5
    return 0;          // 6
}                      // 7
  1. #include copies a ready-made library into your program. iostream gives cin (keyboard input) and cout (screen output).
  2. Lets you write cout instead of std::cout.
  3. main() is where every program starts. int means it hands back a whole number when finished.
  4. 4 & 7: { } mark the start and end of a block.
  5. << sends text to the screen. Every statement ends with a semicolon ;.
  6. 0 tells the system “finished without trouble”.
Comments are notes ignored by the compiler: // one line or /* many lines */. endl or "\n" moves to a new line.

3. Variables, data types, constants

A variable is a named box in memory that stores a value. You must declare it (say its type) before use: int age = 17;

TypeStoresExample
intwhole numbers45, -3
float / doubledecimals (double is more precise)3.14
chara single character in ' ''A'
booltrue or falsetrue
stringtext in " " (needs <string>)"Asha"

Identifier rules (names): letters, digits, underscore only; cannot start with a digit; no spaces; cannot be a keyword (reserved word such as int, if, class); C++ is case-sensitive (Age ≠ age). A constant never changes: const float PI = 3.14;. Type casting converts a type: (float)5/2 gives 2.5, while 5/2 gives 2 because int divided by int drops the decimal.

More about types, tokens and output

Tokens (smallest units) are: keywords, identifiers, constants (literals), operators, punctuators/separators. Types are of three groups: built-in (int, float, char, bool, void), derived (array, function, pointer, reference) and user-defined (structure, union, enum, class).

  • enum gives names to numbers: enum day {MON, TUE, WED}; (MON=0, TUE=1…).
  • union is like a structure but all members share the same memory, so only one holds a value at a time.
  • typedef makes a new name: typedef unsigned int uint;
  • Reference variable is a second name for the same variable: int &r = a;
  • Escape sequences: \n new line, \t tab, \\ backslash, \" quote, \0 null.
  • Manipulators (<iomanip>): endl, setw(8) (field width), setprecision(2).
  • Type conversion: implicit (automatic, smaller to bigger type) and explicit (casting by you).
  • Scope resolution :: reaches a global variable hidden by a local one, or a class member defined outside the class.
  • Library functions: <cmath> sqrt(), pow(), abs(); <cctype> isalpha(), isdigit(), toupper(), tolower(); <cstdlib> exit(), rand(); also goto label; jumps to a label (avoid it).

Input and output

int a;
cout << "Enter number: ";
cin >> a;                 // reads from keyboard
cout << "You typed " << a;

Remember the arrows: cout << (data goes out to the screen) and cin >> (data comes in to the variable).

5. Decisions: if, else, switch

if (marks >= 75) cout << "Distinction";
else if (marks >= 35) cout << "Pass";
else cout << "Fail";

The computer checks conditions top to bottom and runs only the first true one. Use { } if more than one statement belongs inside. An if inside an if is called nested if.

switch (choice) {
  case 1: cout << "Add"; break;     // break stops falling into next case
  case 2: cout << "Subtract"; break;
  default: cout << "Invalid";       // when nothing matches
}

switch works with int/char values, not ranges. Forgetting break is a classic mistake.

6. Loops: repeating work

for (int i = 1; i <= 3; i++)     // start; keep-going condition; step
    cout << i << " ";            // prints 1 2 3

Trace it like the computer: i=1 → 1≤3 true → print 1 → i becomes 2 → print 2 → i becomes 3 → print 3 → i becomes 4 → 4≤3 false → stop.

LoopUse whenChecks condition
foryou know how many timesbefore each round
whileunknown number of timesbefore each round
do-whilemust run at least once (menus)after each round
int n = 5, fact = 1;
while (n > 1) { fact *= n; n--; }   // fact = 5*4*3*2 = 120

break exits a loop; continue skips to the next round. A loop inside a loop (nested) is used for patterns and tables: the inner loop completes fully for every one step of the outer loop.

for (int r = 1; r <= 3; r++) {
  for (int c = 1; c <= r; c++) cout << "*";
  cout << endl;
}   // *  then **  then ***

7. Arrays and strings

An array stores many same-type values under one name: int m[4] = {50, 60, 70, 80};. Positions (index) start at 0, so m[0] is 50 and the last is m[3]. Using m[4] is out of range (a bug).

int sum = 0;
for (int i = 0; i < 4; i++) sum += m[i];   // total of all marks

2-D array (rows and columns, like a table/matrix): int t[2][3]; t[1][2] = 9;. A string in C is a char array ending with a hidden '\0' (null) character: char name[10] = "Ravi";. Handy functions from <cstring>: strlen(s) length, strcpy(a,b) copy, strcat(a,b) join, strcmp(a,b) compare.

Reading strings: cin >> s stops at a space, so for a full line use cin.getline(s, 30); or gets(s);. A string can also be handled with a pointer: char *p = "Hello";. The C++ string class (#include <string>) lets you join with +, compare with == and use s.length().

8. Functions

A function is a named, reusable block of code. It avoids repeating yourself and makes programs easier to read.

int add(int x, int y) {      // x, y = parameters
    return x + y;            // sends result back
}
int main() { cout << add(3, 4); }   // 3, 4 = arguments; prints 7

Parts: return type, name, parameters, body. void means “returns nothing”. A prototype (int add(int,int);) placed above main tells the compiler the function exists. Pass by value: a copy is sent, original unchanged. Pass by reference (void f(int &x)): the original is changed. Scope: a variable inside a function is local (visible only there); one declared outside all functions is global. Function overloading: same name, different parameters. Default arguments: void f(int a, int b = 10). Recursion: a function calling itself (e.g. factorial) – it must have a stopping case.

More on functions (often asked)

  • Inline function: inline int sq(int x){return x*x;} – compiler pastes the code at each call, which saves call time (good for tiny functions; not for big or recursive ones).
  • Return by reference: int &big(int &a,int &b) returns the variable itself, not a copy.
  • Passing arrays: send the array name (its address), so the function can change the original: void show(int a[], int n).
  • Call by pointer: void swap(int *x,int *y){int t=*x;*x=*y;*y=t;} called as swap(&a,&b);
  • Types of functions: library (built-in) and user-defined.
  • Overloading rule: parameters must differ in number or type; return type alone is not enough.

9. Structures

An array holds same-type data. A structure groups different types into one unit:

struct Student { int roll; char name[20]; float per; };
Student s1 = {1, "Asha", 88.5};
cout << s1.name;          // dot operator reaches a member

A structure is the stepping stone to a class: a class is a structure that also contains functions and can hide data.

10. Pointers

Every variable lives at a memory address. A pointer is a variable that stores an address.

int a = 10;
int *p = &a;     // & = "address of a"; p now points to a
cout << *p;      // * = "value at that address" → 10
*p = 20;         // changes a itself to 20

Pointers and arrays are linked: an array name is the address of its first element, so *(m+1) equals m[1]. Dynamic memory: int *q = new int; grabs memory while the program runs; delete q; gives it back. A pointer to a pointer, this pointer (the object itself) and null pointer (points nowhere) also come up in exams.

More on pointers

  • Pointer arithmetic: p++ moves to the next element (jumps by the size of the type, e.g. 4 bytes for int). Allowed: +, −, ++, −−. Not allowed: adding two pointers.
  • Array of pointers: char *names[3] = {"Ram","Sita","Gita"};
  • Pointer to a function: int (*fp)(int,int) = add; fp(2,3);
  • Dynamic array: int *a = new int[5]; delete [] a;
  • this pointer: a hidden pointer in every member function that holds the address of the calling object; this->roll is the object’s own roll.
  • Pointer vs reference: a pointer can be changed to point elsewhere and can be null; a reference is fixed to one variable for life.
  • Uses of pointers: dynamic memory, passing by address, arrays and strings, linked lists and trees.

11. Object-Oriented Programming

The idea

Think of a Car. The blueprint says every car has a colour and speed (data) and can start and brake (actions). Each real car built from it is different. In C++: blueprint = class; real car = object; data = data members; actions = member functions.

class Student {
  private:                       // hidden from outside
    int roll; float per;
  public:                        // usable from outside
    void set(int r, float p) { roll = r; per = p; }
    void show() { cout << roll << " " << per; }
};
int main() {
    Student s;          // object
    s.set(1, 90.5);     // call member function with dot
    s.show();
}

Functions can also be defined outside the class using the scope resolution operator: void Student::show() {...}.

Access specifiers

private: only inside the class (default). public: anywhere. protected: inside the class and its child classes.

The four pillars

PillarMeaningReal-life
Encapsulationbundle data + functions, hide datamedicine capsule
Abstractionshow essentials, hide detailsyou press a TV remote without knowing the circuits
Inheritancechild class reuses parent classchild gets traits from parents
Polymorphismone name, many behaviours“+” adds numbers and joins words

Constructor and destructor

A constructor has the class’s name, no return type, and runs automatically when an object is created (used to set starting values). Types: default (no parameters), parameterised, copy. A destructor ~Student() runs automatically when the object dies (cleanup).

class Box {
  int l;
 public:
  Box() { l = 1; }            // default constructor
  Box(int x) { l = x; }       // parameterised
  ~Box() { cout << "bye"; }   // destructor
};
Box a;  Box b(5);

Inheritance

class Person { public: char name[20]; };
class Student : public Person {   // Student is the child
  public: int roll;               // has name AND roll
};

Types: single (A→B), multilevel (A→B→C), multiple (A and B→C), hierarchical (A→B and A→C), hybrid (mix). Benefit: code reuse.

Polymorphism

Compile-time: function overloading and operator overloading (making + work on your own objects). Run-time: virtual functions – the right function is chosen while the program runs, based on the actual object.

Class vs structure; objects in detail

In a structure members are public by default and it normally has only data; in a class members are private by default and it holds data + functions. You can make an array of objects (Student s[3]; then s[1].show();), pass an object to a function, and return an object from a function. Record = a group of related fields about one entity (a structure variable).

Constructors in full

  • Default: no parameters. Parameterised: takes values. Copy constructor: makes a new object from an old one: Box(Box &b){ l=b.l; } used as Box c(a);
  • Characteristics: same name as class; no return type (not even void); called automatically; usually public; can be overloaded; cannot be inherited or virtual.
  • Destructor characteristics: name is ~ClassName; no arguments and no return type; only one per class (cannot be overloaded); called automatically when the object goes out of scope or is deleted; objects are destroyed in reverse order of creation.

Static members and friend function

class Count {
  static int n;                 // ONE copy shared by all objects
 public:
  Count() { n++; }
  static void show() { cout << n; }   // can use only static data
};
int Count::n = 0;               // must define outside the class

A friend function is not a member, but the class gives it permission to read private data. Declared with the keyword friend inside the class; called like a normal function (no dot); it receives the object as an argument.

class Box {
  int l;
 public:
  Box(int x) { l = x; }
  friend void print(Box b);     // permission slip
};
void print(Box b) { cout << b.l; }   // reaches private l

Friend class and ++ overloading (extra)

Friend class: class A { friend class B; ... }; lets every member function of B use A’s private data. Overloading ++: prefix Num operator++() { ++v; return *this; }; postfix has a dummy int: Num operator++(int) { Num t=*this; v++; return t; }. Object assignment: a = b; copies every data member from b to a (same class).

Inheritance in full

ModeParent’s public becomesParent’s protected becomes
publicpublicprotected
protectedprotectedprotected
privateprivateprivate

Parent’s private members are never directly accessible in the child. Terms: base/parent/super class and derived/child/sub class. Constructor order: base constructor runs first, then derived; destructors run in reverse. Ambiguity in multiple inheritance is solved with ::. In hybrid/diamond inheritance, a virtual base class (class B : virtual public A) keeps just one copy of A. Advantages: reuse, less code, easy extension, real-world hierarchy.

Polymorphism in full

  • Function overloading – same name, different parameters (compile time).
  • Operator overloading – give a new meaning to an operator for objects, with the keyword operator. Cannot overload: :: . .* ?: sizeof.
    class P { int x; public: P(int a=0){x=a;}
  P operator+(P o){ return P(x+o.x); }  // p3 = p1 + p2;
};
  • Virtual function – declared with virtual in the parent; when a parent pointer points to a child object, the child’s version runs (run time, “late binding”). Pure virtual: virtual void f() = 0;. A class with one is an abstract class: you cannot make objects of it; children must define the function.
  • Compile-time (early/static) binding vs run-time (late/dynamic) binding is a common one-line question.

Operator overloading in detail

Rules: only existing operators can be overloaded (you cannot invent new ones); at least one operand must be a user-defined type (an object); the operator’s precedence and number of operands cannot change. A member function gets the left object as itself (so a unary operator takes 0 arguments, a binary operator takes 1); a friend function takes all operands as arguments (unary 1, binary 2).

class Num { int v; public: Num(int a=0){v=a;}
  void operator-() { v = -v; }            // unary: -n1;
  Num operator+(Num o){ return Num(v+o.v);} // binary member
  friend Num operator*(Num a, Num b);       // binary friend
};
Num operator*(Num a, Num b){ return Num(a.v*b.v); }

Type conversion with classes

Built-in types convert automatically, but for your own classes you must tell C++ how:

  • Basic to class – use a constructor with one argument: Num n = 5; calls Num(int).
  • Class to basic – use a conversion (casting) operator function inside the class: operator int() { return v; } so int x = n; works. It has no return type and no arguments.
  • Class to class – either a constructor in the destination class that takes the source object, or a conversion operator in the source class.

Other class topics from the syllabus

  • Constructor overloading and default arguments: Box(); Box(int); Box(int a, int b=1);
  • Dynamic constructor: allocates memory with new inside the constructor (e.g. a name of any length); the destructor then uses delete.
  • Object as a member of another class (nested objects / containership) – “has-a” relation, versus inheritance which is “is-a”.
  • Pointer to object: Student s, *p = &s; p->show(); (arrow -> replaces the dot).
  • Virtual destructor: make the parent’s destructor virtual so deleting a child through a parent pointer destroys the child properly. Virtual functions cannot be static or constructors.

Inline functions: see Section 8.

12. File handling

Variables vanish when a program ends. A file on disk keeps data permanently. Include <fstream>.

ofstream out("stud.txt");     // output file stream: WRITE
out << "Asha 90";
out.close();

ifstream in("stud.txt");      // input file stream: READ
char n[20]; int m;
in >> n >> m;
in.close();

Remember: open → use → close. fstream does both. Modes: ios::in (read), ios::out (write, erases old), ios::app (add at end), ios::binary. Useful: eof() (end reached?), get()/put() (one character), read()/write() (whole objects), seekg/seekp (jump to position), tellg/tellp (current position).

File handling – the complete picture

  • Stream classes (from <fstream>): ifstream (read), ofstream (write), fstream (both). They come from istream/ostream.
  • Two ways to open: constructor ofstream f("a.txt"); or f.open("a.txt", ios::app);. Check success with if(!f) cout << "cannot open";
  • Text file: stores readable characters. Binary file: stores raw bytes (faster, smaller; use ios::binary).
  • Sequential access: read/write from start to end. Random access: jump anywhere with seekg()/seekp() and find the position with tellg()/tellp() (g = get/read pointer, p = put/write pointer). ios::beg, ios::cur, ios::end say where to count from.
Student s;                         // write and read whole objects
ofstream o("st.dat", ios::binary);
o.write((char*)&s, sizeof(s));  o.close();
ifstream i("st.dat", ios::binary);
while (i.read((char*)&s, sizeof(s))) s.show();   // loop ends at end of file
i.close();

Other names: eof() true at end, fail() true on error, close() saves and releases the file.

Extra topics from the revised syllabus

  • Applications of OOP: simulation, CAD/CAM, games, databases, real-time systems, GUI systems, AI.
  • Nested class: a class declared inside another. Memory for objects: each object has its own copy of the data members; member functions are stored once and shared; a static member has one copy for all.
  • Independent reference: a reference declared as a separate variable, int &r = a; (must be initialised, cannot be changed to refer elsewhere).
  • Pointer to derived class: a base-class pointer can hold the address of a derived object, but without virtual it reaches only base members.
  • Rules for virtual functions: must be members of a class, cannot be static, are called through a base pointer, prototypes must match exactly, constructors cannot be virtual (destructors can).
  • Steps to overload an operator: (1) create the class; (2) declare the operator function (member or friend); (3) define it; (4) use the operator on objects.
  • String functions (<cstring>): strlen, strcpy, strncpy, strcat, strcmp, strchr, strstr (Turbo C++ also has strrev, strupr, strlwr).
  • Derived-class constructors: base constructor runs first; pass its arguments with Derived(int a,int b) : Base(a) { ... }. Destructors run in reverse order.
  • Inheritance conflict (ambiguity): two parents with the same member name; fix with A::show(); or a virtual base class.
  • Command-line arguments: int main(int argc, char *argv[]); argc = number of arguments, argv[ ] = the arguments as strings, argv[0] = program name.
